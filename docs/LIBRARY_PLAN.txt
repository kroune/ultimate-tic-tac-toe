# План разработки TypeScript библиотеки Ultimate Tic-Tac-Toe
# ============================================================

## Обзор

Создание отдельного TypeScript модуля для игры супер-крестики-нолики 9×9
без внешних зависимостей. Библиотека будет иметь чистую архитектуру с
разделением на типы, модели малой/глобальной доски и игровой движок.
Включает полное покрытие юнит-тестами.

## Этапы разработки

### Этап 1: Настройка окружения
- Добавить TypeScript, Jest и ts-jest в package.json
- Создать tsconfig.json с strict: true
- Настроить Jest для TypeScript

### Этап 2: Типы и интерфейсы (types.ts)

Определить следующие типы:

  type Player = 'X' | 'O';

  type CellState = Player | null;

  interface Position {
    row: number;  // 0-2
    col: number;  // 0-2
  }

  interface GlobalPosition {
    boardRow: number;  // 0-2 (позиция малой доски на глобальной)
    boardCol: number;  // 0-2
    cellRow: number;   // 0-2 (позиция клетки внутри малой доски)
    cellCol: number;   // 0-2
  }

  type SmallBoardStatus =
    | { type: 'playing' }
    | { type: 'won'; winner: Player }
    | { type: 'draw' };

  interface GameState {
    currentPlayer: Player;
    activeBoard: Position | null;  // null = можно ходить на любую
    globalBoard: SmallBoardStatus[][];  // 3x3 статусы малых досок
    boards: CellState[][][];  // 3x3 массив малых досок (каждая 3x3)
    isGameOver: boolean;
    winner: Player | null;
  }

  type MoveResult =
    | { success: true; newState: GameState }
    | { success: false; error: string };

  interface GameResult {
    winner: Player | null;  // null = ничья
    wonBoardsX: number;
    wonBoardsO: number;
  }

### Этап 3: Класс SmallBoard (small-board.ts)

Ответственность: логика одной малой доски 3×3

Поля:
  - cells: CellState[][] (3x3)
  - status: SmallBoardStatus

Методы:
  - constructor()
  - makeMove(row: number, col: number, player: Player): boolean
  - checkWinner(): Player | null
  - isFull(): boolean
  - getStatus(): SmallBoardStatus
  - getAvailableMoves(): Position[]
  - getCell(row: number, col: number): CellState
  - clone(): SmallBoard (для иммутабельности, если потребуется)

### Этап 4: Класс GlobalBoard (global-board.ts)

Ответственность: управление 9 малыми досками

Поля:
  - boards: SmallBoard[][] (3x3)

Методы:
  - constructor()
  - getSmallBoard(row: number, col: number): SmallBoard
  - getGlobalStatus(): SmallBoardStatus[][] (статусы всех малых досок)
  - checkGlobalWinner(): Player | null
  - countWonBoards(player: Player): number
  - isSmallBoardPlayable(row: number, col: number): boolean
  - getPlayableBoards(): Position[]
  - clone(): GlobalBoard

### Этап 5: Класс GameEngine (game-engine.ts)

Ответственность: основной игровой движок, объединяющий всё

Поля:
  - globalBoard: GlobalBoard
  - currentPlayer: Player
  - activeBoard: Position | null  // куда должен пойти текущий игрок
  - isGameOver: boolean
  - winner: Player | null
  - moveHistory: GlobalPosition[] (опционально)

Методы:
  - constructor()
  - makeMove(boardRow: number, boardCol: number,
             cellRow: number, cellCol: number): MoveResult
  - getValidMoves(): GlobalPosition[]
  - getCurrentPlayer(): Player
  - getActiveBoard(): Position | null
  - getGameState(): GameState
  - isGameOver(): boolean
  - getWinner(): Player | null
  - getGameResult(): GameResult | null
  - reset(): void
  - serialize(): string (для сохранения)
  - static deserialize(data: string): GameEngine (для загрузки)

Логика makeMove():
  1. Проверить, что игра не окончена
  2. Проверить, что ход в разрешённую доску:
     - Если activeBoard !== null, ход должен быть на эту доску
     - Если activeBoard === null, ход на любую играбельную доску
  3. Проверить, что целевая клетка свободна
  4. Сделать ход на малой доске
  5. Проверить победу на малой доске
  6. Проверить глобальную победу
  7. Определить следующую activeBoard:
     - Если доска по координатам (cellRow, cellCol) играбельна → activeBoard = {cellRow, cellCol}
     - Иначе → activeBoard = null (свободный выбор)
  8. Сменить игрока
  9. Вернуть результат

### Этап 6: Вспомогательные функции (utils.ts)

  - checkLine(a: CellState, b: CellState, c: CellState): Player | null
  - checkWinnerOnGrid(grid: CellState[][]): Player | null
  - isValidPosition(row: number, col: number): boolean
  - deepClone<T>(obj: T): T

## Дополнительные соображения

### Сериализация/Десериализация
Рекомендуется реализовать для:
- Сохранения игры в localStorage
- Передачи состояния по сети (мультиплеер)
- Отката к предыдущему состоянию

### История ходов
Опционально добавить:
- moveHistory: GlobalPosition[]
- undo(): MoveResult
Полезно для UI (кнопка "Отменить ход"), но усложняет код.

### Иммутабельность
Методы могут возвращать новые объекты вместо мутации.
Упрощает интеграцию с React/Vue, но может влиять на производительность.
Рекомендую: мутабельные методы + clone() для копирования при необходимости.
